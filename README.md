# Kutub Uddin — Portfolio Website
A responsive static portfolio using a light, approachable editorial style inspired by the supplied Ali Abdaal website reference. All wording and design are adapted for Kutub Uddin's apparel sourcing and merchandising profession; this is not a copy of the source website.

## Deploy to GitHub Pages
1. Create a GitHub repository (for a user site, name it `YOURUSERNAME.github.io`).
2. Upload the contents of this folder to the repository root.
3. Open Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Check the generated URL on mobile and desktop.

## Before publication
- Confirm every employment date/title and education wording against your records.
- Replace the CSS garment illustrations with approved real product imagery when available. The current visuals are clearly illustrative.
- Add only case studies, client names, logos, results and metrics you are authorized to publish.
- Contact form opens a prefilled email in the visitor's email app. It does not send/store data on a server.
- No analytics or visitor tracking is included.
- Google Fonts loads from an external CDN. Remove font links if you prefer a no-third-party-request setup.

Files: `index.html`, `styles.css`, `script.js`, `assets/`, `robots.txt`, `404.html`.

## Editing the sections

Open `index.html` in a code editor and search for `id="testimonials"`, `id="buyers"`, and `id="certifications"`. Edit the card text directly. To replace slide images, put approved images in `assets/images/product-slides/` and update the corresponding image `src` in the product presentation section. Original PDFs are in `assets/documents/`.

## Publish on GitHub Pages

1. Extract the ZIP.
2. Upload the contents of the `Final Web site - Copy` folder to the root of your GitHub repository (so `index.html` is at the repository root).
3. In GitHub, open **Settings → Pages** and select the `main` branch and `/ (root)`.
4. Wait for the Pages deployment to finish, then open the URL GitHub provides.

The contact form opens the visitor's email app; it does not submit to a server. Use only approved, non-confidential project material on a public repository.
